# Fast Travel Anywhere

A **Borderlands GOTY / GOTY Enhanced** mod for the [willow1-mod-manager](https://github.com/bl-sdk/willow1-mod-manager) that adds a keybind to open the Fast Travel / Respec menu from anywhere, without walking to a New-U station.

## Features

- **Open Fast Travel Menu/Respec keybind:** brings up the same New-U station screen you get at a fast travel point. From it you can:
  - fast travel to any location you've already unlocked
  - respec your skill points
- Pressing the key on the main menu or a loading screen does nothing (no errors).
- No other options, hooks or settings files. It's just the keybind.

## Requirements

- Borderlands GOTY or Borderlands GOTY Enhanced
- [willow1-mod-manager](https://github.com/bl-sdk/willow1-mod-manager) (the Python SDK)

## Installation

1. Download [`FastTravelAnywhere.sdkmod`](https://github.com/OngoGablogian/OngoBL1Mods/raw/refs/heads/main/Fast%20Travel%20Anywhere/FastTravelAnywhere.sdkmod) from this repository.
2. Copy it into your `sdk_mods` folder, inside your Borderlands install's `Binaries` folder.
3. Start the game and open **Mods** from the main menu.
4. Choose **Fast Travel Anywhere** and make sure it's enabled.
5. Open **Keybinds** and assign a key to **Open Fast Travel Menu/Respec**. No key is bound by default.

## Usage

- When you're in the game, press your bound key to open the Fast Travel / Respec menu.

## Compatibility note

- This keybind was taken from **Bonk Utilities**. If you also run Bonk Utilities, unbind its *Open Fast Travel Menu/Respec* key (or disable that mod) so the menu isn't opened twice by the same key.
